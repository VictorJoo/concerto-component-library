컴포넌트 라이브러리 콘체르토 매니저 · v0.1

시안(Provisional) — 색상 값은 로그인 배너 브랜드 자산에서 뽑은 시작점이다. 기획은 semantic 역할(성공/경고/위험/정상/정보 = 의미 매핑)과 표기 규칙까지 정하며, 정확한 hex 확정·최종 승인은 디자인/프론트 소관이다.

1. 표기 규칙 (Convention)

본 라이브러리가 따르는 색상 토큰 표기 규칙. 화면·컴포넌트는 아래 규칙을 전제로 색을 참조한다.

① 2계층 토큰 Primitive(원시 램프, indigo-600)는 화면에서 직접 쓰지 않고, Semantic(역할 토큰, --primary)만 참조한다.
② 표기법 hex 기본. 형식은 shadcn 관례 — CSS 변수 · :root(라이트) / .dark(다크).
③ 라이트·다크 같은 토큰명에 두 값을 둔다. 별도 이름을 만들지 않는다.
④ 네이밍 소문자·하이픈(kebab), 역할→변형 순(primary / primary-foreground).
⑤ 대비 텍스트/배경은 WCAG AA(본문 4.5:1, 큰 텍스트 3:1)로 검증하고 결과를 표기한다(4장).
⑥ 값 출처 로그인 배너 원본에서 픽셀 추출로 확정한다(현재값은 이미지 근사치).
⑦ 문서화 항목 토큰당 이름 / 라이트값 / 다크값 / 용도 / 대비 결과.

2. 원시 색상 (Primitive) — 브랜드 인디고/페리윙클

로그인 배너·GNB 키비주얼에서 추출한 브랜드 램프. 화면에는 직접 쓰지 않고 역할 토큰이 이 값을 참조한다.

indigo (brand)
slate (neutral · cool)

3. 역할 토큰 (Semantic) — 라이트 / 다크

화면에서 실제로 참조하는 토큰. 각 토큰은 라이트·다크 두 값을 가진다. 기능색(성공·경고·위험)은 상태 구분을 위해 브랜드 블루에서 분리한다.

4. 대비 검증 (WCAG AA)

주요 텍스트/배경 조합의 실제 대비비. 본문 4.5:1, 큰 텍스트 3:1 이상이면 통과.

5. shadcn 토큰 정의 (형식 참고용)

색 토큰을 shadcn CSS 변수 형식으로 정리한 시안이다. 형식 참고용이며, 확정 값·최종 반영은 디자인/프론트가 정한다.

공통정책 조항을 실제 동작으로 확인하는 컴포넌트 모음. 파란 칩이 공통정책 조항 번호와 매핑된다. 색은 탭1 팔레트를 그대로 사용하며, 시각(간격·모션)은 예시로 디자인 라이브러리에서 확정한다.

공통정책 7.77.6

토스트 메시지

동기 작업의 즉시 결과는 토스트로 처리한다. 성공(3초)·실패(5초)·부분 성공(5초, 일괄 작업 한정)을 사용하며, 표시 시간 경과 시 자동 소멸하고 사용자가 수동으로 닫을 수 있다. 본인이 수행한 동기 행위는 별도 알림을 발송하지 않는다.
버튼을 눌러 토스트 확인 (우측 상단)
부분 성공은 일괄 작업에서 일부만 성공한 경우에만 사용한다(형식: {작업명} {N}건 완료, {M}건 실패). 동일 내용 연속 발생 시 최신 1건으로 갱신하며, 비동기 완료·실패는 토스트가 아니라 알림으로 통지한다.
공통정책 7.3

처리 중(로딩) 상태

동기 작업(등록/저장/삭제)은 버튼 클릭 시 완료 전까지 버튼을 비활성화하여 중복 실행을 막고, 스피너로 진행 중임을 표시한다. 버튼 라벨은 유지한다(문구 교체는 구현 재량). 비동기 작업(CDE 프로비저닝·배치)은 버튼에 대기시키지 않고 요청 접수 토스트 후 완료·실패를 알림으로 통지한다.
동기 작업 — 클릭 시 라벨 유지 + 스피너 + 비활성화
비동기(CDE 프로비저닝 등)는 여기에 해당하지 않는다 — 버튼을 붙잡지 않고 "요청했습니다" 접수 토스트 후 완료/실패를 알림으로 통지한다. 진행률 바는 진행 정도를 측정할 수 있는 작업(업로드·다운로드 등)에만 사용한다.
공통정책 4.57.5

모달 · 팝오버 (닫힘 규칙 대비)

모달은 배경 상호작용을 막고 화면 중앙에 배치하며, 외부 클릭·ESC로 닫지 않고 의도적 버튼 클릭만 허용한다. 반대로 팝오버·드롭다운·플라이아웃은 외부 클릭·ESC·트리거 재클릭으로 닫으며 배경 상호작용을 막지 않는다.
